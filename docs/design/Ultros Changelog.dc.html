Changelog

What shipped, when. New releases roughly every two weeks.

Jun 3, 2026 v0.9

Judge calibration reports

New

See how closely each AI judge agrees with your human labels — per rubric criterion, over time. Judges that drift below your agreement threshold are flagged on every run they score.

  • Cohen's κ and exact-agreement shown per criterion
  • One-click re-calibration from a sample of disagreements
May 19, 2026 v0.8

Regression gates for CI

New

Block a merge when a prompt change drops scores. ultros gate --min-delta -0.02 runs the eval in CI and exits non-zero on regression.

  • GitHub Actions and GitLab CI recipes in the docs
  • Gate results posted as a PR comment with the score diff
May 4, 2026 v0.7

Dataset slices

Improved

Tag dataset rows and break every score down by slice — language, difficulty, customer tier. A prompt that improves overall but regresses on a slice now shows as flaky, not passing.

Apr 14, 2026 v0.6

Side-by-side run diffs

Improved

Compare any two runs row by row: outputs, judge reasoning, and score deltas in one view. Rows that flipped from pass to fail sort to the top.

Mar 30, 2026 v0.5

Ultros public beta

Release

Prompt versioning, dataset runs across four providers, rubric-based AI judges, and the run dashboard. The free tier opens to everyone.
